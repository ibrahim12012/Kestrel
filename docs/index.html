A desktop AI assistant for Windows.

Kestrel is a chat assistant that reads your documents, searches the web, sees your screen and answers by voice. When a task needs doing on the machine rather than explaining, it can take the mouse and keyboard and do it, then save what it did as a macro you can run again.

Features

What Kestrel does.

One application covering the whole job, rather than a chat window with automation bolted on. Each of these is a finished part of the app.

Core

Chat

Ask anything. Kestrel answers from the model's own knowledge first, and only offers to act when acting is the answer. Attachments, extended thinking and screenshots all go through the chat box.

Autonomous mode

For multi-step tasks. It says what it intends to do, waits for you to accept, then works one action at a time with a screenshot between each step.

Macros

A finished task is saved as a function the assistant can call by name. The second time you ask, it runs in seconds instead of being worked out again.

Three ways to build a macro

Recorder

Do the task yourself with the recorder running. Clicks, typing and key combos are captured as you go. No AI involved and no API key needed.

Block editor

Every macro opens as a stack of coloured blocks. Drag to reorder, click a value to change it. Any macro you have saved can be dropped into another one as a single block.

UI mapping

Point it at an application and it walks that app's accessibility tree, finds the real buttons and fields, and compiles them into callable actions.

What it can read and produce

Files and documents

Reads PDFs, Word files, spreadsheets, images and text. Writes real files back: Word, PDF, Excel, CSV, Markdown and plain text. Merges a pile of files into one PDF.

Web access

Searches the web, reads a single page as article text rather than raw HTML, or crawls a whole site through its sitemap within a page budget you set.

Voice

Talk instead of typing, with a spoken reply. Optionally call the assistant by name with the wake word. Voice answers the confirmation card too, so a task can run without the keyboard.

Setup and control

Models and profiles

Gemini, OpenAI, Anthropic, or a local model on your own machine. Keep several assistants side by side, each with its own name, model and wake word, and switch between them.

The interface

Light and dark themes that switch instantly, seven languages including right-to-left Arabic, undo for anything destructive, a live console, and a tray icon with a global show and hide.

Safety limits

Shell commands run against a fixed allow-list, risky actions are capped per session, destructive ones need approval every time, and one shortcut stops everything.

How it works

How Kestrel decides what to do.

Every message is checked against three questions in order, so simple requests stay fast and autonomous mode only runs when it is actually needed.

1

Can this be answered directly?

If the model already knows the answer, it answers, then offers to act if that is relevant.

"What is Reddit?" answers, then offers to open it
2

Is there a matching tool or saved macro?

One-step actions and macros you already have run straight away. No screenshots, no waiting.

"Play my chill playlist macro" runs directly
3

Does it need several steps?

Kestrel proposes autonomous mode, waits for confirmation, acts one step at a time, and offers the result as a new macro.

"Search lo-fi music on YouTube" goes autonomous

Safety

What Kestrel can and cannot do on its own.

Kestrel can click, type and run commands on your machine. These are the limits placed on that, and they are enforced in code rather than by the model's judgement.

Low risk

Allow-listed commands only

Shell commands are checked against a fixed allow-list before running, never passed to a shell as a raw string. Chaining, redirection and variable expansion are refused outright.

High risk

Session action caps

Risky actions such as force-closing an application or deleting a file are capped per session, with a separate budget for each risk tier.

Human handoff

Pauses at CAPTCHAs and MFA

When autonomous mode hits a verification challenge, it stops and asks you to take over, then resumes from a fresh screenshot.

Always on

Three ways to stop it

Esc or Ctrl+Alt+X halts any running automation, and throwing the mouse into a screen corner is a failsafe that works regardless.

FAQ

Frequently asked questions.

How does Kestrel control my computer?+

Two ways. Where an application exposes its structure through Windows UI Automation, Kestrel reads the real buttons and fields and clicks them by name. Where it does not, it takes a screenshot, uses the model's vision to find what it needs, and sends mouse and keyboard input, the same input you would send yourself.

Where are my macros stored?+

On your machine, in your user data folder, as plain JSON. Chat and autonomous-mode requests go straight to whichever provider you configured using your own key. There is no Kestrel server in the middle and no account.

Does it work outside the browser?+

Yes. Kestrel drives any Windows application the same way. The browser is one of many apps it can operate.

Can I stop it mid-task?+

Yes. Esc stops a running automation from anywhere, Ctrl+Alt+X does the same on a combination you will not press by accident, and slamming the mouse into a screen corner is a failsafe that does not depend on either.

Does autonomous mode ever act without asking?+

No. There is no tool the model can call to start it. It proposes the task in plain language, the app shows a confirmation card, and only an explicit accept starts a run. It pauses again at a CAPTCHA or an MFA prompt, and anything destructive asks separately.

Do I need my own API key?+

For anything involving the model, yes, and usage is billed by that provider directly. A free Gemini key is enough to use Kestrel properly. A local model needs no key at all. The recorder, the block editor and macro playback all work with no key configured.

Can I pick which model Kestrel uses?+

Yes. A dropdown in chat switches between Gemini, GPT and Claude, and you can point it at a local endpoint instead. Chat, macros, autonomous mode and the safety limits behave the same whichever is active. Voice recognition currently runs through Google's Web Speech API regardless of the model.

Why does my antivirus flag it?+

Because Kestrel installs global keyboard and mouse hooks, sends synthetic input, captures the screen and runs shell commands. That is a description of the product and also a description of a remote access trojan, and no scanner can tell them apart from the outside. The antivirus section of the docs explains what has been done about it and what has not.
