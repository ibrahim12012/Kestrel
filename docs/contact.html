Contact

One address for everything, plus the repository for anything that needs tracking.

Email

leafeon.void@gmail.com reaches the project for anything: a question, a commercial licence, or a security report.

Bugs and feature requests

Open an issue on the repository. It is more useful than email for anything that needs tracking, because other people hitting the same thing can find it. Include your Windows version, which model provider you are using, and the relevant lines from the live console; the console is the single most useful thing you can attach, since it shows what actually ran.

Security

If you have found something that should not be reported in public, email it rather than opening an issue.

Commercial licensing

Email is the right route. See Licensing for when a commercial licence is the one you need.

Contributing

Pull requests are welcome. The test suite runs on any platform, including Linux, with pytest; run it before opening a pull request. Contributions are accepted under the GPL v3.
